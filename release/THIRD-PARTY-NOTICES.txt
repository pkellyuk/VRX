VRX 1.7.9 third-party components

Depth Anything V2 Small, ONNX Community export (Apache-2.0)
https://github.com/DepthAnything/Depth-Anything-V2
https://huggingface.co/onnx-community/depth-anything-v2-small
The supplied FP16-weight ONNX model has been modified to fix input/output shapes
at 686x392, with ONNX shape inference, using bench/make_fixed_shape.py.
See licenses/DepthAnything-LICENSE.txt.

ZipDepth-base (MIT), Fabio Tosi
https://github.com/fabiotosi92/ZipDepth
Default depth model. The zipdepth_base.pth checkpoint has been exported to
a fixed 672x384 ONNX model with FP16 arithmetic and float input/output, keeping
the original global-context attention pooling, using bench/zipdepth_export.py.
See licenses/ZipDepth-LICENSE.txt.
